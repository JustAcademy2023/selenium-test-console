# selenium-test-console

A landing page style field guide to building a Selenium automation testing framework from scratch, covering framework structure, data driven and key driven design, BDD with Cucumber and Gherkin, mobile testing with Appium, and where Selenium sits next to Cypress and Playwright. Built as a single responsive `index.html`, styled like a live test runner console.

## Live demo

Open `index.html` directly in a browser, or enable GitHub Pages on this repository (Settings → Pages → Deploy from branch → main → /root) to host it at `https://<your-username>.github.io/selenium-test-console/`.

## What's inside

- `index.html` — the full landing page, self contained, no build step required
- Responsive layout, tested down to small mobile widths
- A terminal style hero panel with a staggered pass and check animation
- A test suite style overview of every topic the underlying guide covers
- A course and bootcamp section linking to live, mentor led Selenium, Python, JavaScript and MERN stack training in Pune
- A further reading log linking to three related blog posts

## Topics covered in the guide this page summarises

1. Framework structure, starting from an empty folder
2. Data driven testing and key driven framework design
3. Behavior driven development with a Selenium Cucumber framework and Gherkin syntax
4. Mobile testing with Appium and real device coverage
5. Selenium compared with Cypress automation and Playwright automated testing
6. Regression, visual regression and load testing layered on top of functional checks
